# Brakeline Tools website

Static site for Brakeline Tools and FlatPack, served by GitHub Pages from the `main` branch root.

- `index.html`: home page with FlatPack and support
- `privacy.html`: privacy policy (required for the Autodesk App Store listing)
- `assets/`: stylesheet, self-hosted Archivo font (SIL Open Font License), images

No build step, cookies or analytics.
